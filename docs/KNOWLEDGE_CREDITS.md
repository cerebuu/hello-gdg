Only category names are sourced. See FACTS_TO_SOURCE.md for all missing visible
symptoms. Dataset/model performance figures are not app accuracy figures.

Hosted REST references:
https://roboflow.com/blog/inference-providers-for-computer-vision-models

The official hosted examples document the serverless endpoint, base64 or file
input, and Authorization: Bearer header transport. No URL-auth fallback is used.
Real hosted Roboflow inference remains unverified until its private key is set.
