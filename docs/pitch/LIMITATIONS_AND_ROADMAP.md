# Limitations and roadmap

## Limitations

- Advice is **possible**, not confirmed. A phone image is not a laboratory
  diagnosis.
- Live mode needs internet access and a working server connection.
- Bisaya and Filipino wording is still being reviewed by native speakers.
- The app has been tested on limited photos, not on a validated field dataset.
- Current coverage is focused on banana and cacao.
- Sample mode is a demo fallback. It does not infer a result for an uploaded
  photo.
- The current server path uses Gemini live guidance. A knowledge base,
  Roboflow detectors, and second checks are not yet verified or included in
  this shipped deployment.
- An agriculture professional remains important for uncertain, severe, or
  unusual cases.

## Roadmap

1. Build a reviewed knowledge base from trusted agriculture sources.
2. Add and verify Roboflow or other trained detector checks as a second
   opinion, with clear uncertainty.
3. Support more crops and more local dialects.
4. Add extension-officer review and feedback into the product workflow.
5. Replace demo-only material with consented, licensed field photos and
   stronger evaluation before making broader claims.
