# Bisaya Crop Doctor: 3-minute pitch script

## 0:00–0:30 — Hook

“A farmer sees a dark spot on a banana leaf. Is it a disease? Is it damage?
What should happen next?

Today, we are showing Bisaya Crop Doctor. A farmer takes one photo. The app
gives possible guidance in Bisaya or Filipino. It also says what it cannot
know.

This is a decision aid, not a lab diagnosis.”

## 0:30–0:50 — Problem

“A phone photo does not give us a laboratory result. But doing nothing is not
helpful either. Farmers need a clear first step, in language they can use, and
an honest path to an expert.

This is especially useful for banana and cacao growers in the Davao Region.”

## 0:50–1:35 — Live demo walkthrough

“I choose Bisaya. I tap the photo area. I select this banana leaf sample.
I submit it in live mode.

The result uses the word possible. It shows the crop, the possible problem,
uncertainty, actions, and when to call an expert.

I can switch to Filipino. I can copy the report. I can also print a farmer
card.

Now I will show the demo fallback. I choose a sample result. The SAMPLE label
is visible. This is a saved example, not a diagnosis of the photo.”

## 1:35–2:00 — How it works

“The phone sends the selected image to our server only when live mode is
submitted. The server calls Google Gemini with the requested Bisaya or
Filipino language and a structured response. The key stays on the server.

The client renders the response in one consistent format. For a presentation
or a connection problem, the user can explicitly choose a local sample.”

## 2:00–2:20 — Safety and honesty

“We do not say confirmed. We do not give branded chemical names or dosages.
We show the same disclaimer every time. Low-confidence and non-plant images
do not become confident advice. When the situation is unclear, we point to an
agriculture professional.

The app helps with the next question. It does not replace a lab or an
extension officer.”

## 2:20–2:40 — Impact

“The value is a faster, more understandable first step. It can help a farmer
record the concern, share the report, and know when to ask for help.

We are not claiming a measured accuracy rate today. We are showing a careful
prototype with a clear safety boundary.”

## 2:40–2:52 — Roadmap

“Next, we want an agriculture-source knowledge base, trained detector checks as
a second opinion, more crops and dialects, and extension-officer review. The
knowledge base and detector checks are not yet verified or part of the current
live server.”

## 2:52–3:00 — Closing ask

“We are asking for expert review, native-speaker review, and field feedback.
Help us turn a careful first step into a useful tool for Davao farmers.

This is Bisaya Crop Doctor: possible guidance, in a farmer’s language, with
honesty built in.”
